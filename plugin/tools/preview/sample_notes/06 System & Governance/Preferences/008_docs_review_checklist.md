# Docs review checklist

## Core Idea
Before a docs page ships, run every command on the page in a clean folder, open every link and check it lands on the right heading, read each paragraph aloud and cut any sentence that does not help the reader finish the task, check that screenshots match the current interface, and make sure the page says at the top who it is for and what they will have done by the end of it. A reviewer signs off only when all of these pass.
