# Status updates that get read

## Core Idea
Long status updates went unread during the v1 launch, so the team agreed a fixed shape.

Every weekly summary opens with one sentence on what shipped, then a short list of what is blocked and who can unblock it, then the decisions that need an answer this week. Keep it under two hundred words, link each item to its task, and leave out anything that did not change since last week so the reader can finish it in a minute.

The same shape now works for the onboarding emails project.
